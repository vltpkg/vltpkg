Usage:

<Code code="$ vlt logout" title="Terminal" lang="bash" />

Log out of the default registry, deleting the token from the local
keychain, as well as destroying it on the server.

To target a specific configured registry by alias, use
[`vlt registry <alias> logout`](/client/commands/registry). See
[Targeting a specific registry](/client/registries#targeting-a-specific-registry).
