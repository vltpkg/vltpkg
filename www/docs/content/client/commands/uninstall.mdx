Usage:

<Code
  code="$ vlt uninstall [package ...]"
  title="Terminal"
  lang="bash"
/>

The opposite of `vlt install`. Removes deps and updates vlt-lock.json
and package.json appropriately.

## Options

### `--global`, `-g`

Uninstall [global packages](/client/commands/install#global-installs),
removing their workspace, and their bins from every folder vlt linked
them into.

<Code code="$ vlt uninstall -g eslint" title="Terminal" lang="bash" />

`vlt uninstall -g vlt` removes a `vlt` installed as a global package.
For a `vlt` installed with npm or Homebrew it prints the command to
use instead.

## Aliases

```
rm, u
```
