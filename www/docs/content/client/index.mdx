## Installation

<Code
  code="$ curl -fsSL https://install.vlt.sh | bash"
  title="Terminal"
  lang="bash"
/>

`vlt` requires Node.js 22.22 or later.

Update it with `vlt install -g vlt`, see
[Updating vlt](/client/commands/install#updating-vlt). Install other
command line tools the same way, see
[Global Installs](/client/global-installs).
