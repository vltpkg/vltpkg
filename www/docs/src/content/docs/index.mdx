## Introducing vlt

vlt (/vōlt/ pronounced "volt") is the platform for Javascript
packages. It delivers the tools and infrastructure to meet the
challenges of modern Javascript supply chain management, so teams can
ship and maintain packages more easily.

[vlt.io](https://vlt.io/onboarding-signup) serves as a drop-in
replacement for the npm registry.
